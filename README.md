Explicação do Sistema

O sistema consiste em um Conversor Universal de Unidades, uma aplicação interativa de linha de comando (CLI) desenvolvida para realizar conversões exatas entre diferentes grandezas físicas.

A interação com o usuário ocorre de forma direta pelo terminal. O programa apresenta um menu de opções onde o usuário pode selecionar a categoria da grandeza, inserir o valor numérico de origem e definir para qual unidade de medida deseja convertê-lo. As categorias suportadas pelo sistema incluem:

Temperatura: Conversões entre graus Celsius, Fahrenheit e Kelvin.
Distância: Conversões entre quilômetros, metros, milhas e pés.
Massa: Conversões entre quilogramas, gramas, libras e onças.

A aplicação lê a entrada do usuário, aplica a regra matemática correspondente à conversão escolhida e exibe o resultado final formatado na tela. O sistema também possui validações de entrada para garantir que o fluxo não seja interrompido caso o usuário digite letras ou caracteres inválidos no lugar de números.

Tecnologias Utilizadas
Linguagem de Programação: Python 
Interface: Command Line Interface (CLI)
